hallowelt42 / samtpfote

Miso zieht bei dir ein.

Eine kleine interaktive Katze für deine Webseite. Kostenlos für private und gewerbliche Nutzung, mit verpflichtender Namensnennung von hallowelt42.

Wichtig: Die sichtbare Signatur "hallowelt42 / samtpfote" und die Herkunftshinweise im Quellcode müssen erhalten bleiben. Die vollständigen Nutzungsbedingungen stehen in LIZENZ.txt.

1. Das Paket ablegen

Entpacke das Paket. Kopiere den enthaltenen Ordner samtpfote in das öffentliche Verzeichnis deiner Webseite. Er enthält die fertige Datei samtpfote.js und die optionale Schnurr-Aufnahme im Unterordner audio. Die Dateien werden von deiner eigenen Webseite ausgeliefert. Es gibt keine externen Skriptaufrufe oder Schriftanfragen.

Die Beispieldatei beispiel.html zeigt den vollständigen Einbau. Öffne sie über einen lokalen Webserver. Das direkte Öffnen von Modulen als lokale Datei wird von Browsern häufig eingeschränkt.

2. Diesen Code einfügen

<script type="module" src="/samtpfote/samtpfote.js"></script>

<samt-pfote
  cat-name="Miso"
  position="bottom-right"
  coat="black"
  sleep-after="35"
  style="--cat-size: 220px; --cat-offset: 16px"
></samt-pfote>

Die Katze hat einen transparenten Hintergrund. Sofa, Lampe und Pflanze gehören ausschließlich zur Demo und werden nicht eingebunden. Ohne position steht die Katze im normalen Dokumentfluss. Verwende eine freie Ecke, damit sie keine Bedienelemente verdeckt.

3. Deine Einstellungen

Attribut oder StilWirkung
cat-nameName der Katze. Ohne Angabe gilt der zentrale Name Miso. Die Urhebernennung bleibt davon unabhängig.
positionbottom-right, bottom-left, top-right oder top-left.
coatblack für warmes Schwarz, cream für Creme, smoke für Warmgrau, auto für Schwarz im hellen und Creme im dunklen Systemmodus.
sleep-afterSekunden bis zum Einschlafen, Standard 35. Schläfrigkeit beginnt nach 62 Prozent dieser Zeit.
--cat-sizeBreite einschließlich Bewegungsraum. Die Katze selbst ist etwas kleiner. Standard 220px; auf kleinen Bildschirmen in Seitenecken auf 35vw begrenzt.
--cat-offsetAbstand zur Ecke, Standard 16px zuzüglich sicherer Bildschirmränder.
--cat-z-indexDarstellungsebene der festen Katze, Standard 10000.
pausedDas vorhandene Attribut pausiert. Zum Fortsetzen entfernen.

4. Echtes Schnurren einschalten

Das Schnurren bleibt ohne Angabe einer Datei ausgeschaltet. Für echtes Schnurren beim Anklicken oder Knuddeln ergänze:

<samt-pfote
  position="bottom-right"
  coat="black"
  sound-src="/samtpfote/audio/schnurren.mp3"
  volume="35"
></samt-pfote>

Die Lautstärke reicht von 0 bis 100. Ton startet ausschließlich durch eine bewusste Streichelaktion und wird weich ein- und ausgeblendet. Browser können Tonwiedergabe einschränken. Die echte Aufnahme ist gemeinfrei; Herkunft und Bearbeitung stehen in HERKUNFT.txt.

5. Verhalten ausprobieren

Augen und Kopf folgen dem Zeiger. Bleibt er etwa 1,3 Sekunden in der Nähe der Nase, tatzt Miso gegen eine gedachte Scheibe und zeigt die Pfotenballen. Nach einer Ruhepause folgt ein Nickerchen. Die Schlafzeichen steigen auf und verschwimmen. Nach acht Sekunden Schlaf taucht gelegentlich eine Traumwolke mit einer Computermaus auf. Mausbewegung, Scrollen, Tastatur und Berührung wecken die Katze sanft. In den Seitenecken macht die Katze nach 3 Sekunden Mausaufenthalt in ihrer Nähe mit kleinen Seitwärtsschritten Platz. Ist der ursprüngliche Bereich wieder frei, kehrt sie nach einer Pause zurück. Auf dem Sofa bleibt sie am Platz. Bei reduzierter Bewegung entfallen dekorative Dauerbewegungen und zufällige Aktionen.

const cat = document.querySelector('samt-pfote');
cat.perform('petting');    // Knuddeln
cat.perform('swatting');   // Tatzen
cat.perform('stretching'); // Strecken
cat.perform('grooming');   // Putzen
cat.perform('sleeping');   // Träumen
cat.perform('auto');       // Eigener Rhythmus
cat.addEventListener('catstate', ({ detail }) => {
  console.log(detail.state, detail.label);
});

6. Komponente im eigenen Projekt

Der Ordner komponente enthält den Quellcode einschließlich Cat.svelte. Übernimm den vollständigen Ordner. Die Komponente lädt das Browsermodul erst nach dem Einhängen und eignet sich auch für serverseitig gerenderte Seiten.

<script>
  import Cat from './komponente/Cat.svelte';
</script>

<Cat size={220} position="bottom-right" coat="black" />

7. Einen zentralen Namen verwenden

Im Quellcode steht der zentrale Wert CAT_NAME in config.js. Die Demo und die erzeugte Anleitung nutzen ihn gemeinsam. Für einzelne Einbindungen verwende cat-name oder die Komponenteneigenschaft name. Die Namensänderung ersetzt nicht die sichtbare Pflichtnennung "hallowelt42 / samtpfote".

Ein Geschenk von hallowelt42. samtpfote darf kostenlos mitgenommen werden, solange die Namensnennung erhalten bleibt.
